# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its text is incorporated here by reference. It applies in every project space: issues, pull requests, discussions, reviews and any other channel the project runs. It also applies when someone represents the project in public.

In short: be respectful and constructive, assume good faith, and keep the discussion on the work. Harassment, personal attacks, discriminatory language and publishing other people's private information are not tolerated.

## Reporting

Please report unacceptable behaviour to the project maintainer, [@antonarnaudov](https://github.com/antonarnaudov):

- Until a dedicated conduct address is published in this file, reach the maintainer privately through the contact details on their GitHub profile.
- For abuse on GitHub itself, you can also use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature.

Every report is reviewed, and the reporter's privacy is respected. Security problems are reported differently: see [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer enforces this code of conduct. They follow the Contributor Covenant 2.1 [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines), which range from a correction to a permanent ban.
